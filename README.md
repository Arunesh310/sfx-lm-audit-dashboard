# LM Audit Team's Reports Summary

Shadowfax dashboard for **nine LM Audit reports** (P0 Metrics, Shipments Tally, CB, Intransit, LM ODC, DCH, Fwd High Ageing, Open runsheet, Reverse Pendency). Logic from *Intransit Pendency logic (end to end) (7)* · Oct 10, 2026.

## Run locally

```bash
npm install
npm run dev
```

Edit report copy in **`src/data/reports.ts`**.

## Deploy

Push to `main` on GitHub; Vercel deploys from the connected repo.
