# Pendency report coverage dashboard

Shadowfax LM dashboard for the **eight pendency reports** (Intransit, LM ODC, Open runsheet, Reverse, Fwd High Ageing, CB, Shipments Tally, P0 Metric). Logic sourced from the end-to-end pendency document (Oct 10, 2026). All reports publish **by 9:30 AM IST** daily.

## Run locally

```bash
npm install
npm run dev
```

Edit report copy in **`src/data/reports.ts`**.
